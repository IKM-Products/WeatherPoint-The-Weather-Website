# 🌦️ WeatherPoint: The Weather Website
<img width="1920" height="923" alt="Screenshot (203)" src="https://github.com/user-attachments/assets/ef55a7ce-0e22-4691-bb2d-ceae196997bc" />

**WeatherPoint** is a simple and user-friendly weather web application that provides real-time weather information based on user location or searched cities. It is built using modern web technologies and powered by the Open-Meteo API.

## 🚀 Features

* 🌍 **Real-Time Weather Data** - Fetches live weather information including: Temperature, Humidity & Wind Speed

* 🔎 **City-Based Search** - Users can search for weather conditions in any city worldwide.

* 🧾 **Clean & Simple UI** - Minimal and responsive design for easy usability.

* ⚡ **Fast & Lightweight** - Optimized for quick loading and smooth performance.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Code Editor:** Visual Studio Code
* **API:** Open-Meteo API 

## 📱 How It Works

1. User opens the website.
2. The app fetches weather data using Open-Meteo API.
3. User can search for a city manually.
4. Weather details are displayed instantly on the screen.

## 🎯 Objective

The main objective of **WeatherPoint** is to provide a simple, fast, and accessible platform for users to check real-time weather conditions without complexity.
