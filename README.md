# 🌦️ WeatherPoint: The Weather Website

**WeatherPoint** is a simple and user-friendly weather web application that provides real-time weather information based on user location or searched cities. Built using modern web technologies and powered by the Open-Meteo API, the website delivers accurate weather updates in a clean and minimal interface.

## 🚀 Features

* 🌍 **Real-Time Weather Data**
  Fetches live weather information including:

  * Temperature
  * Humidity
  * Wind Speed
  * Rainfall

* 🔎 **City-Based Search**
  Users can search for weather conditions in any city worldwide.

* 📍 **Location-Based Weather**
  Displays weather data based on the user's current location.

* 🧾 **Clean & Simple UI**
  Minimal and responsive design for easy usability.

* ⚡ **Fast & Lightweight**
  Optimized for quick loading and smooth performance.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Code Editor:** Visual Studio Code
* **API:** Open-Meteo API 

## 📱 How It Works

1. User opens the website.
2. The app fetches weather data using Open-Meteo API.
3. User can:

   * Allow location access for current weather
   * Search for a city manually
4. Weather details are displayed instantly on the screen.

## 🎯 Objective

The main objective of **WeatherPoint** is to provide a simple, fast, and accessible platform for users to check real-time weather conditions without complexity.
